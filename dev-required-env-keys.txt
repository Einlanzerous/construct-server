# dev-required-env-keys.txt — keys the DEV stack cannot run without (SERV-173)
#
# Dev's copy of required-env-keys.txt: one key NAME per line, every one of which must
# reach /opt/construct-server-dev/.env with a non-empty value or deploy-dev.yml fails
# before it pulls anything. Read that file's header for the rules; they are the same
# here, with the DEV_ prefix where dev's names differ (SERV-77, SERV-97) and against
# the `construct-server-dev` vault project and DEV_ENV_FILE.
#
# DELIBERATELY ABSENT: DEV_CLOUDFLARE_TUNNEL_TOKEN and DEV_CLOUDFLARE_TUNNEL_ID. The
# tunnel token is the dev edge's on-switch (SERV-93) — the Makefile enables the `edge`
# profile exactly when it is present — so "not set" is a legal, documented state and
# not a dropped credential. Requiring it here would turn switching the edge off into a
# failed deploy.
